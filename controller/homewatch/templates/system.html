Import

Replaces all settings with the ones in an export file. The current settings are kept as a version first, so you can go back under Configuration versions. Passwords, tokens and users stay as they are, except credentials of a module or channel whose address changes or whose HTTPS or certificate check is turned off: those are deleted and it is switched off.

Configuration versions

{{ note("versions") }}

homewatch keeps the last 200 versions of its settings: modules, thresholds, timing, home, weekly report, channels and maintenance windows. Restoring one is saved as a new version, so it can be undone. Passwords, tokens and users are not part of a version and stay as they are, except credentials of a module or channel whose address changes or whose HTTPS or certificate check is turned off: those are deleted and it is switched off.
